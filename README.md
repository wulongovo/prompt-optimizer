# ⚡ Prompt优化器 (Prompt Optimizer)

自动化Prompt工程优化平台。输入任务描述和测试用例，自动生成6种策略的Prompt变体，通过LLM-as-Judge评估打分，迭代优化找到最优Prompt。

## 工作流程

```
用户输入: 任务描述 + 测试用例
              ↓
┌──────────────────────────────────────┐
│  Step 1: 生成6种Prompt变体            │
│  零样本 | 少样本 | 思维链 | 角色扮演  │
│  结构化输出 | 组合优化                │
├──────────────────────────────────────┤
│  Step 2: LLM-as-Judge 4维评分        │
│  准确性 + 完整性 + 格式 + 简洁性      │
├──────────────────────────────────────┤
│  Step 3: 迭代优化Top3 → 重新评估      │
├──────────────────────────────────────┤
│  输出: 排名 + 最优Prompt + 评分图表   │
└──────────────────────────────────────┘
```

## 6种优化策略

| 策略 | 说明 | 最佳场景 |
|------|------|----------|
| 零样本 | 不提供示例，直接指令 | 简单任务 |
| 少样本 | 提供输入输出示例 | 格式敏感任务 |
| 思维链 | 引导分步推理 | 逻辑推理任务 |
| 角色扮演 | 赋予专家角色 | 专业领域任务 |
| 结构化输出 | 要求JSON/Markdown | 数据提取任务 |
| 组合优化 | 综合多种策略 | 复杂任务 |

## 使用

```bash
pip install -r requirements.txt
python main.py serve    # Web服务 http://localhost:8001
python main.py strategies
```
